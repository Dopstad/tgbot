# Бот-напоминалка

Telegram-бот: задачи фразами и через меню, предупреждения «заранее», повторы
(каждый день, по дням недели, каждый месяц), утренняя сводка.

## Где что лежит

| Файл | За что отвечает |
|---|---|
| `bot.py` | запуск (10 строк) |
| `app/core.py` | токен, часовой пояс, сам бот, текущее время |
| `app/db.py` | вся работа с базой `tasks.db` |
| `app/dates.py` | повторы и даты: когда сработает следующее напоминание, тексты «за 2 часа» |
| `app/parser.py` | разбор фраз («завтра в 15:00, напомни за 30 минут») |
| `app/scheduler.py` | фоновая проверка каждые 20 секунд: напоминания, «заранее», сводка |
| `app/ui.py` | экраны меню: тексты и кнопки |
| `app/wizard_ui.py` | экраны пошаговых мастеров (создание и изменение задач) |
| `app/nav.py` | показ экранов с удалением старых |
| `app/handlers/` | обработчики: `basic`, `menu`, `tasks`, `wizard`, `digest`, `reminders`, `quick` |
| `app/main.py` | сборка и запуск |
| `tests/` | автопроверки |

## Проверка перед загрузкой на сервер

    python3 -m unittest discover -s tests -t .

Все точки в ответе = всё в порядке. Буква `F` или `E` = что-то сломано, вывод покажет что.

## Как добавить функцию

1. Найди файл по таблице выше (текст кнопки: `ui.py`; новая команда: нужный файл в `handlers/`).
2. Измени только его.
3. Запусти проверки.
4. Загрузи на GitHub изменённые файлы, нажми «Пересобрать» на хостинге.
